攻略チャート

冒険の流れを10章に分けて、やることを順番に並べました。章をタップすると手順が開きます。

ストーリーの流れは64版と同じです。Switch 2版では城下町などの配置が一部変わっているため、細かい位置は「時の軌跡」で確認してください。

01コキリの森 〜 デクの樹サマの中こども
  1. 森の修行場の小さな穴をくぐった先の宝箱でコキリの剣を入手
  2. ショップでデクの盾（40ルピー）を買う。ルピーは草や岩の下から集める
  3. ミドの前を通ってデクの樹サマに話しかけ、ダンジョン「デクの樹サマの中」へ
  4. ボスのゴーマを倒すとコキリのヒスイ。森の出口の橋でサリアから妖精のオカリナをもらう

入手:コキリの剣デクの盾パチンコ妖精のオカリナコキリのヒスイ

ダンジョン攻略:デクの樹サマの中

02ハイラル平原 〜 ハイラル城こども
  1. 平原で夜を越すと城下町の跳ね橋が開く。城下町でマロンと会い、タロンを探してと頼まれる
  2. ハイラル城の前でマロンからコッコのタマゴ。時間経過でコッコにかえる
  3. 城の横で眠るタロンをコッコで起こし、木箱を水路に押して堀を越える
  4. 見張りの兵に見つからないよう中庭を抜けてゼルダに会う。帰り道でインパからゼルダの子守歌

入手:ゼルダの手紙ゼルダの子守歌

03ロンロン牧場 〜 ドドンゴの洞窟こども
  1. ロンロン牧場でマロンと話してエポナの歌を覚える（大人になってから必須）
  2. カカリコ村を経由し、デスマウンテン登山道の門番にゼルダの手紙を見せる
  3. 迷いの森の奥、森の聖域でサリアからサリアの歌を習う
  4. ゴロンシティのダルニアの前でサリアの歌を演奏するとゴロンのブレスレット
  5. バクダン花で入口を開けて「ドドンゴの洞窟」へ。キングドドンゴを倒してゴロンのルビー

入手:エポナの歌サリアの歌ゴロンのブレスレットバクダン袋ゴロンのルビー

ダンジョン攻略:ドドンゴの洞窟

04ゾーラの里 〜 時の神殿こども
  1. ゾーラ川の滝の前でゼルダの子守歌を演奏し、ゾーラの里へ入る
  2. ハイリア湖の底でビンに入ったルトの手紙を拾い、キングゾーラに見せる
  3. ビンに魚を入れてジャブジャブ様に与え、「ジャブジャブ様のお腹」へ
  4. バリネードを倒してゾーラのサファイア。城の前でゼルダから時のオカリナを受け取り時の歌を覚える
  5. 時の神殿で3つの精霊石をそなえ、時の歌で扉を開けてマスターソードを抜く → 7年後へ

入手:ルトの手紙（ビン）ブーメランゾーラのサファイア時のオカリナ時の歌

ダンジョン攻略:ジャブジャブ様のお腹

057年後 〜 森の神殿大人
  1. 目覚めた時の神殿でシークから光のプレリュード（時の神殿へのワープ）
  2. カカリコ村の墓地でダンペイの霊とレースをしてフックショットを入手
  3. ロンロン牧場でインゴーとのレースに2回勝ち、エポナを連れ出す
  4. 森の聖域でシークから森のメヌエット。フックショットで上の入口から「森の神殿」へ

入手:光のプレリュードフックショットエポナ森のメヌエット妖精の弓森のメダル

ダンジョン攻略:森の神殿

06デスマウンテン 〜 炎の神殿大人
  1. ゴロンシティで転がる子ゴロン（リンク）を止めるとゴロンの服（熱さに耐えられる）
  2. デスマウンテンの火口でシークから炎のボレロ
  3. 「炎の神殿」で捕まったゴロン族を助けながら進み、メガトンハンマーで先へ

入手:ゴロンの服炎のボレロメガトンハンマー炎のメダル

ダンジョン攻略:炎の神殿

07氷の洞窟 〜 水の神殿大人
  1. 凍ったゾーラの里の奥から「氷の洞窟」へ。シークから水のセレナーデと鉄のブーツ
  2. 青い炎をビンに入れ、凍ったキングゾーラを溶かしてゾーラの服（水中で息ができる）
  3. ハイリア湖の底から「水の神殿」へ。ゼルダの子守歌で水位を3段階に切り替えて進む

入手:水のセレナーデ鉄のブーツゾーラの服ロングフック水のメダル

ダンジョン攻略:氷の洞窟水の神殿

08カカリコ村 〜 井戸の底 〜 闇の神殿両方
  1. 大人でカカリコ村に入るとシークから闇のノクターン
  2. 子供に戻り、風車小屋で嵐の歌を覚えて演奏すると井戸の水が引く
  3. 「井戸の底」でデッドハンドを倒してまことのメガネ
  4. 大人に戻り、闇のノクターンで墓地の上へワープして「闇の神殿」へ

入手:闇のノクターン嵐の歌まことのメガネホバーブーツ闇のメダル

ダンジョン攻略:井戸の底闇の神殿

09ゲルドの谷 〜 魂の神殿両方
  1. ゲルドの谷の橋をエポナで飛び越え、ゲルドの砦で捕まった大工4人を救出 → ゲルドの会員証
  2. 門を開けて幻影の砂漠へ。まことのメガネで案内役の幽霊を追う
  3. 巨大邪神像の前でシークから魂のレクイエム
  4. 子供で入って銀のグローブ、大人で入ってミラーシールドを取り、ツインローバを倒す

入手:ゲルドの会員証魂のレクイエム銀のグローブミラーシールド魂のメダル

ダンジョン攻略:魂の神殿ゲルドの修練場

10ガノン城（最終章）大人
  1. 時の神殿で正体を明かしたゼルダから光の矢
  2. 6人の賢者の力でガノン城への虹の橋がかかる
  3. 城内6つの結界を光の矢で破り、塔の最上階でガノンドロフと対決
  4. 崩れる城からゼルダと脱出したあと、最後の戦いへ

入手:光の矢

ダンジョン攻略:ガノン城
